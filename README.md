# 몬스터헌터 와일즈 길드 장비 공방

몬스터헌터 와일즈(Monster Hunter Wilds) 헌터들을 위한 장비 스탯 도감 및 5부위 커스텀 장비 시뮬레이터입니다. 방어구별 가성비, 5대 속성 내성 밸런스, 발동 스킬을 실시간으로 분석해 보세요!

---

## ⚔️ 주요 기능

- **📜 방어구 스탯 탐색기**: 스킬/부위/랭크별 필터링, 가성비 점수(스킬+슬롯) 순위 및 방어력·내성 전체 스탯 도감
- **⚒️ 커스텀 장비 시뮬레이터**: 머리·가슴·팔·허리·다리 5부위 조합에 따른 종합 물리 방어력, 5대 속성 내성 레이더 차트, 발동 스킬 실시간 합산
- **📖 세트 & 스킬 도감**: 전체 방어구 세트 구성 및 스킬별 상세 효과 사전

---

## 🛠️ 기술 스택

- **프레임워크**: Python 3.12, Streamlit
- **데이터 분석**: Pandas
- **시각화**: Plotly
- **데이터 소스**: MH Wilds Database API (`wilds.mhdb.io`)
