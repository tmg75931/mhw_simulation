# 몬스터헌터 와일즈 대시보드 프로젝트 개발 지침 (Agent Handoff)

## 1. 프로젝트 개요
본 프로젝트는 '몬스터헌터 와일즈(Monster Hunter Wilds)' 유저들을 위한 장비 및 스탯 분석 대시보드를 구축하는 것입니다. 별도의 백엔드 데이터베이스(DB)를 구축하지 않고, 외부 API에서 데이터를 호출하여 메모리에 캐싱하는 '가벼운 아키텍처'를 채택합니다.

## 2. 기술 스택
- **언어:** Python 3.10+
- **프론트엔드 & 대시보드 프레임워크:** Streamlit
- **데이터 처리:** Pandas
- **데이터 시각화:** Plotly (또는 Altair)
- **API 통신:** Requests

## 3. 데이터 소스 및 아키텍처
- **데이터 소스:** MH Wilds API (`https://docs.wilds.mhdb.io/`)
- **타겟 데이터:** 방어구(Armor), 방어구 세트(Armor Sets), 스킬(Skills) JSON 데이터
- **아키텍처 제약사항 (중요):**
  - **No Database:** MySQL, PostgreSQL 등 RDBMS나 NoSQL을 사용하지 않습니다.
  - **데이터 로드:** 앱 실행 시 `requests`를 통해 API 데이터를 호출합니다.
  - **메모리 캐싱:** API 통신 비용을 줄이고 렌더링 속도를 높이기 위해 반드시 Streamlit의 `@st.cache_data` 데코레이터를 사용하여 호출된 JSON/DataFrame 데이터를 캐싱합니다.

## 4. 주요 기능 명세

### Feature 1: 방어구 스탯 및 가성비 탐색기 (Gear Stats Explorer)
- **기능 설명:** 특정 스킬을 검색 및 필터링하여 방어구를 찾고, 스탯을 시각적으로 비교합니다.
- **UI 요소:**
  - 검색 필터: 텍스트 입력(스킬명 검색) 및 드롭다운(부위별 필터링).
  - 데이터 테이블: 필터링된 방어구 리스트 출력 (`st.dataframe` 활용).
- **시각화 (Plotly Scatter Plot):**
  - X축: 물리 방어력 (Defense)
  - Y축: 특정 속성 내성 (예: 불 속성 내성)
  - 툴팁: 방어구 이름 및 보유 스킬 표시.

### Feature 2: 와일즈 커스텀 장비 시뮬레이터 (Custom Set Builder)
- **기능 설명:** 유저가 방어구 5부위를 선택했을 때 종합 스탯과 발동 스킬을 계산하여 시각화합니다.
- **UI 요소:**
  - 5개의 드롭다운 메뉴 (머리, 가슴, 팔, 허리, 다리).
  - 총합 물리 방어력 텍스트 출력.
- **시각화:**
  - **속성 내성 (Plotly Radar Chart):** 불, 물, 번개, 얼음, 용 속성의 합계 내성을 방사형 다각형 차트로 시각화.
  - **발동 스킬 (Plotly Bar Chart):** 장비 조합으로 발동된 스킬의 총합 레벨을 누적 막대그래프(가로형)로 표시.

## 5. 개발 에이전트를 위한 단계별 구현 지침 (Step-by-Step)

1. **Phase 1: 데이터 파이프라인 구축**
   - `requests`로 API에 GET 요청을 보내는 함수를 작성하세요.
   - `@st.cache_data`를 적용하여 데이터를 캐싱하세요.
   - 받아온 JSON 데이터를 처리하기 쉬운 `pandas.DataFrame` 형태로 전처리하세요.

2. **Phase 2: Streamlit 기본 레이아웃 구성**
   - `st.set_page_config`를 사용해 페이지 전체 레이아웃을 'wide'로 설정하세요.
   - 사이드바(`st.sidebar`) 또는 탭(`st.tabs`)을 활용하여 '탐색기(Explorer)'와 '시뮬레이터(Builder)' 메뉴를 분리하세요.

3. **Phase 3: 탐색기 (Explorer) 탭 구현**
   - 사용자 입력을 받는 위젯을 상단에 배치하고, 하단에 Plotly 산점도 차트와 데이터프레임을 나란히 렌더링하세요.

4. **Phase 4: 시뮬레이터 (Builder) 탭 구현**
   - 장비 부위별 선택 드롭다운을 만들고, 선택된 장비들의 스탯(방어력, 내성, 스킬)을 합산하는 로직을 작성하세요.
   - 합산된 데이터를 바탕으로 Plotly Radar Chart와 Bar Chart를 렌더링하세요.

**주의 사항:**
코드를 작성할 때 한 번에 모든 것을 구현하려 하지 말고, 먼저 API 데이터를 정상적으로 가져와 화면에 단순 텍스트로 출력하는 프로토타입부터 작성하여 점진적으로 고도화하세요.
